Citation counts in `_data/publications.json` are build-time fallback snapshots. The crawler can fall back to old Scholar data while still advancing its `updated` field, so neither that field nor a successful workflow alone guarantees fresh Scholar results.

## Preview Analytics

The semantic `footer#footer.homepage-footer` always renders its static copyright, name, and `Last updated` metadata, including on local previews. It has no separate background, gradient, or shadow. The date uses `time[datetime]` in `YYYY-MM-DD` format, with a visible month/year such as `Oct. 2026`. Only analytics are hidden by default.

Visitor requests are production-only. Set the fixed production HTTPS origin in `_config.yml` under `visitor_statistics_origin`; the footer exposes that dedicated value through `data-site-origin`. Do not substitute `site.url`: `jekyll serve` may rewrite it to localhost, making an origin guard accidentally accept the preview. `assets/js/site-traffic.js` requires HTTPS and an exact match between the browser `location.origin` and the configured origin. Localhost, alternate-port, and other preview origins must neither request visitor services nor show counters. A localhost referrer bucket can contain unrelated traffic and must not be presented as this homepage's visits.

The only visible visitor metric is the existing `visitor-badge.laobi.icu` service, labeled `Total Visitors` at a quiet 18px height. Both source colors are `%23000000`; CSS `invert(1)` and `opacity: 0.7` turn that input into a white/gray badge, not a black badge. Preserve its exact `page_id=https://xiaoxi-li1.github.io/`, including the trailing slash, so styling does not reset or change the historical bucket. `.visitor-badge` starts hidden; its direct-child image stores the HTTPS source in `data-badge-source` and has no initial `src` or `srcset`. On the canonical origin, load the SVG directly once and reveal it only after a successful image load. Do not fetch and then fall back to an image request: this service has no CORS support, and the extra request can count an extra visit. Never hardcode a retrieved total, insert a placeholder, or bypass the guard to populate a preview screenshot.

Busuanzi continues production-only background PV collection, independently of the visible badge. Its `.site-traffic[hidden][aria-hidden=true]` container retains an empty PV value and must never be revealed; UV markup stays commented out. Do not substitute Busuanzi numbers for the visible service or reactivate ClustrMaps. ## Build and Review

In the current shared environment, first run `export BUNDLE_PATH=/opt/tiger/homepage-review-20261009/bundle` to reuse the installed locked gems. On another machine, install the locked bundle normally instead of relying on this local path.

From the repository root, build and check the default output:

```bash
bundle exec jekyll build --safe
bundle exec ruby docs/check_publications.rb
```

To check a custom preview build in the current shared environment:

```bash
bundle exec jekyll build --safe --destination /opt/tiger/homepage-review-20261009/preview
bundle exec ruby docs/check_publications.rb /opt/tiger/homepage-review-20261009/preview/index.html
```

The main stylesheet and four local JS entrypoints use `relative_url` plus `?v={{ site.time | date: '%s' }}` to prevent a new page from reusing an old cached theme or script. Keep all five on the same build version and preserve their existing `defer` behavior; this uses standard Liquid and works with GitHub Pages safe builds and local rebuilds without a metadata API or plugin. Do not pin `time` in `_config.yml`, which would freeze this version.

For asset changes, test an already-used browser with the previous assets cached, not only a clean session or hard refresh. The new page must request the new versioned URLs and render the current styles. The checker verifies shared versions, built asset existence, and script loading attributes; a warm-cache browser check covers the actual cache transition.

The checker is offline. It validates approved counts and ordering, source metadata and asset existence, HTTPS syntax, complete and collapsed authors, team overrides, journal labels, the exact 16-paper CCF mapping, thumbnails, local navigation, duplicate DOM IDs, and the native image dialog. It checks the Seed2.1 banner's approved metadata, dimensions, source labels, and versioned URLs without confusing the original input hash with exported WebP checksums. It also checks metric sources, compact snapshot labels, configured thresholds, and each metric's initial `hidden` state against the strict comparison, independently for Stars and citations. The two profile totals are checked separately for valid snapshots, rounded Stars labels, inline sentence placement, exact text/link hooks, and visibility without paper thresholds. A failure prints specific reasons and exits nonzero. It does not decode image contents, crawl unrelated legacy links, verify remote availability or acceptance claims, execute runtime network updates, or replace a visual review.

Before **every push**, show the local preview to the user and obtain confirmation. Check desktop and mobile layout, author expansion, section navigation, and figure enlargement with keyboard and pointer input. A passing build/check is necessary but is not permission to publish. Work on `main` as requested; do not push automatically after running these commands.
